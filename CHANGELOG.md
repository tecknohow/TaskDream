# Changelog

All notable changes to TaskDream will be documented in this file.

## [0.1.0] - 2026-04-13

### Added
- Initial project scaffold
- Go backend with Echo framework and xorm ORM
- Vue 3 + TypeScript frontend with Vite and Pinia
- Task CRUD with priorities, due dates, and labels
- Project management with kanban board view
- User authentication (JWT)
- Time tracking module (inspired by Super Productivity)
- Notes module (inspired by Tududi)
- Areas for organizing projects
- Calendar view for tasks
- Dark/light mode support
- Docker support with multi-stage build
- GitHub Actions CI pipeline
